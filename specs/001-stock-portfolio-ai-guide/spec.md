# Feature Specification: 계좌별 주식 보유 관리와 AI 투자 가이드

**Feature Branch**: `001-stock-portfolio-ai-guide`

**Created**: 2026-11-05

**Status**: Draft

**Input**: User description: "주식관리 플랫폼 stock management를 개발해줘. 사용자가 자신의 보유 계좌별
주식정보 (계좌명, 종목명, 평단가)를 등록할수 있어야한다. 주식 정보는 한국, 미국주식 둘다
가능해야한다. 나의 주식 종목명 옆에는 현재가를 표시 및 색구분 필요 (상승 빨강, 하락 파랑).
종목별 가이드 버튼을 두고 버튼을 누르면 ai 를 통해 주가를 분석하고 현재 나의 상황에 맞는
가이드를 준다. ai 는 클로드, open ai 등을 선택할수 있다. 가이드 버튼은 하루 최대 2번 누를 수
있고, 가이드 정보를 기록해야한다."

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 계좌별 보유 종목 등록 (Priority: P1)

사용자는 증권 계좌를 하나 이상 만들고(예: "키움 일반", "미래에셋 ISA"), 각 계좌에 보유한 종목을
등록한다. 종목은 한국(KOSPI·KOSDAQ) 또는 미국(NYSE·NASDAQ 등) 시장에서 검색해 고르고, 평단가와
보유 수량을 입력한다. 등록한 종목은 계좌별로 묶여 목록에 보이며, 수정과 삭제가 가능하다.

**Why this priority**: 보유 정보가 없으면 현재가 표시와 AI 가이드 모두 의미가 없다. 이 스토리만으로도
흩어진 계좌의 보유 현황을 한 화면에서 정리하는 가치가 있다.

**Independent Test**: 계좌 2개를 만들고 한국 종목 1개, 미국 종목 1개를 각각 등록한 뒤, 목록에서
계좌별로 올바른 종목·평단가·수량·통화가 보이는지 확인한다. 수정·삭제 후 결과가 반영되는지 확인한다.

**Acceptance Scenarios**:

1. **Given** 계좌가 없는 사용자, **When** 계좌명 "키움 일반"으로 계좌를 만들면, **Then** 빈 계좌가
   목록에 나타난다.
2. **Given** 계좌 "키움 일반", **When** "삼성전자"를 검색해 선택하고 평단가 71,500원·수량 10주를
   입력해 저장하면, **Then** 해당 계좌 아래에 삼성전자가 원화(₩) 평단가와 함께 표시된다.
3. **Given** 계좌 "미래에셋 해외", **When** "AAPL"을 검색해 선택하고 평단가 $185.20·수량 5주를
   저장하면, **Then** 해당 계좌 아래에 Apple이 달러($) 평단가와 함께 표시된다.
4. **Given** 같은 종목이 이미 등록된 계좌, **When** 같은 종목을 다시 등록하려 하면, **Then** 중복
   등록을 막고 기존 항목을 수정하도록 안내한다.
5. **Given** 등록된 종목, **When** 평단가를 0 이하, 수량을 0 이하로 입력하면, **Then** 저장되지
   않고 해당 입력란 옆에 오류 메시지가 표시된다.
6. **Given** 종목이 들어 있는 계좌, **When** 계좌를 삭제하면, **Then** 확인 대화상자가 나타나고
   승인 시 계좌와 그 안의 보유 종목이 함께 삭제된다.

### User Story 2 - 현재가 및 등락 색상 표시 (Priority: P2)

사용자가 보유 목록을 열면 각 종목명 옆에 현재가가 표시된다. 전일 종가 대비 상승이면 빨간색,
하락이면 파란색, 보합이면 기본 색(회색 계열)으로 표시하고, 등락 금액과 등락률도 함께 보여준다.
또한 내 평단가 대비 평가손익과 수익률을 같은 색 규칙으로 표시한다.

**Why this priority**: 등록한 보유 정보에 시세를 붙여야 사용자가 현재 상황을 판단할 수 있다.
AI 가이드도 이 현재가를 바탕으로 한다.

**Independent Test**: 상승 종목·하락 종목·보합 종목이 하나씩 있는 상태에서 목록을 열고, 각 종목의
현재가 숫자와 색상이 규칙대로인지, 장중 일정 시간 뒤 값이 갱신되는지 확인한다.

**Acceptance Scenarios**:

1. **Given** 전일 종가 70,000원인 종목의 현재가가 71,000원, **When** 목록을 보면, **Then** 현재가
   71,000원과 "+1,000 (+1.43%)"가 빨간색으로 표시된다.
2. **Given** 전일 종가 $190.00인 종목의 현재가가 $187.50, **When** 목록을 보면, **Then** 현재가
   $187.50과 "-2.50 (-1.32%)"가 파란색으로 표시된다.
3. **Given** 평단가 71,500원·수량 10주, 현재가 71,000원, **When** 목록을 보면, **Then** 평가손익
   -5,000원(-0.70%)이 파란색으로 표시된다.
4. **Given** 장이 열린 시간, **When** 사용자가 목록을 열어 둔 채 기다리면, **Then** 현재가가 최대
   1분 간격으로 갱신되고 마지막 갱신 시각이 표시된다.
5. **Given** 시세를 가져오지 못한 종목, **When** 목록을 보면, **Then** 해당 종목만 "시세 없음"과
   마지막으로 받은 값·시각을 표시하고 나머지 종목은 정상 표시된다.
6. **Given** 장 마감 이후, **When** 목록을 보면, **Then** 마지막 종가를 표시하고 "장 마감" 상태임을
   표시한다.

### User Story 3 - 종목별 AI 투자 가이드 요청 (Priority: P3)

사용자는 보유 종목 옆의 "가이드" 버튼을 눌러, 선택한 AI(예: Claude, OpenAI)가 해당 종목의 주가
흐름을 분석하고 내 평단가·수량·수익률을 고려한 가이드(보유 유지, 추가 매수, 분할 매도 검토 등과
그 근거, 주요 위험 요인)를 받는다. 가이드 버튼은 하루 최대 2번까지 사용할 수 있다.

**Why this priority**: 이 플랫폼의 차별 기능이지만, 등록(P1)과 현재가(P2)가 있어야 의미 있는 분석이
가능하다.

**Independent Test**: 종목 하나에서 가이드 버튼을 눌러 결과를 받고, 같은 날 두 번째 요청이 되며
세 번째 요청은 막히는지, 남은 횟수 표시가 맞는지 확인한다.

**Acceptance Scenarios**:

1. **Given** 오늘 "삼성전자" 가이드를 사용하지 않은 상태, **When** 삼성전자의 가이드 버튼을 누르면,
   **Then** 진행 중 표시가 나타나고, 완료되면 분석 요약·현재 상황 진단·행동 가이드·위험 요인·면책
   문구가 담긴 가이드가 표시되며 삼성전자의 남은 횟수가 1로 줄어든다.
2. **Given** 오늘 "삼성전자" 가이드를 2번 사용한 상태, **When** 삼성전자의 가이드 버튼을 보면,
   **Then** 버튼이 비활성화되고 "이 종목의 오늘 사용 가능 횟수를 모두 사용했습니다. 내일 00:00(KST)에
   초기화됩니다."가 표시된다.
3. **Given** 오늘 "삼성전자" 가이드를 2번 사용한 상태, **When** "AAPL"의 가이드 버튼을 보면,
   **Then** AAPL의 남은 횟수는 2로 표시되고 버튼이 활성화되어 있다.
4. **Given** 등록된 AI 키가 하나도 없는 상태, **When** 가이드 버튼을 누르면, **Then** 가이드를
   요청하지 않고 AI 키 등록 화면으로 안내한다.
5. **Given** AI 공급자를 "OpenAI"로 설정한 사용자, **When** 가이드를 요청하면, **Then** 결과에
   어떤 AI 공급자·모델이 생성했는지 표시된다.
6. **Given** AI 응답이 실패하거나 시간 초과된 경우, **When** 가이드 요청이 끝나면, **Then** 오류
   안내가 표시되고 사용 횟수는 차감되지 않는다.
7. **Given** 가이드 요청이 진행 중, **When** 사용자가 버튼을 다시 누르면, **Then** 중복 요청이
   발생하지 않는다.

### User Story 4 - AI 공급자 키 등록과 선택 (Priority: P3)

사용자는 설정에서 자신이 가진 AI 공급자(Claude, OpenAI 등) API 키를 등록하고, 키가 등록된 공급자 중
가이드 생성에 사용할 공급자를 고른다. AI 호출 비용은 사용자 본인의 키로 청구된다.

**Why this priority**: 가이드(US3)를 쓰려면 최소 1개의 키가 필요하다. US3과 함께 출시해야 하며,
최소 구현은 공급자 1개 키 등록이다.

**Independent Test**: Claude 키와 OpenAI 키를 등록하고 공급자를 Claude에서 OpenAI로 바꾼 뒤 가이드를
요청해, 결과에 OpenAI가 표시되는지 확인한다.

**Acceptance Scenarios**:

1. **Given** 키가 없는 상태, **When** Claude API 키를 입력해 저장하면, **Then** 키 유효성을 확인한
   뒤 저장하고, 화면에는 끝 4자리만 보이도록 가려서 표시한다.
2. **Given** 잘못된 키를 입력한 경우, **When** 저장하면, **Then** 저장하지 않고 "키를 확인할 수
   없습니다" 오류를 표시한다.
3. **Given** Claude와 OpenAI 키가 모두 등록된 상태, **When** 공급자를 OpenAI로 선택해 저장하면,
   **Then** 다음 가이드 요청부터 OpenAI가 사용된다.
4. **Given** OpenAI 키만 등록된 상태, **When** 공급자 선택 목록을 보면, **Then** Claude는 "키 필요"로
   표시되어 선택할 수 없다.
5. **Given** 선택한 공급자가 키 만료·잔액 부족·일시 장애로 응답하지 않는 경우, **When** 가이드를
   요청하면, **Then** 원인을 구분한 안내(키 확인 필요 / 일시 장애)가 표시되고 횟수는 차감되지 않는다.
6. **Given** 등록된 키, **When** 키를 삭제하면, **Then** 확인 단계를 거쳐 삭제되고, 그 공급자가
   선택되어 있었다면 선택이 해제된다.

### User Story 5 - 가이드 기록 조회 (Priority: P4)

사용자는 종목별로 과거에 받은 가이드 기록을 시간 역순으로 볼 수 있다. 각 기록에는 요청 시각, 사용한
AI 공급자·모델, 요청 당시의 현재가·평단가·수량·수익률, 가이드 본문이 남아 있다.

**Why this priority**: 과거 가이드와 실제 주가 흐름을 비교해 판단을 돌아볼 수 있게 하지만, 기록 저장
자체는 US3에서 이루어지므로 조회 화면은 나중에 추가해도 된다.

**Independent Test**: 서로 다른 날 가이드를 2건 받은 뒤 기록 화면에서 2건이 최신순으로, 요청 당시
스냅샷 값과 함께 보이는지 확인한다.

**Acceptance Scenarios**:

1. **Given** 가이드 기록이 3건 있는 종목, **When** 기록 화면을 열면, **Then** 3건이 최신순으로
   표시된다.
2. **Given** 가이드를 받은 뒤 평단가를 수정한 경우, **When** 기록을 보면, **Then** 기록에는 요청
   당시의 평단가가 그대로 남아 있다.
3. **Given** 가이드 기록이 있는 보유 종목을 삭제한 경우, **When** 가이드 기록 화면을 보면, **Then**
   기록은 유지되며 "보유 종료" 상태로 표시된다.

### Edge Cases

- 거래 정지·상장 폐지된 종목: 현재가 대신 상태("거래정지", "상장폐지")를 표시하고 가이드 버튼은
  비활성화한다.
- 같은 종목을 여러 계좌에 보유: 계좌별로 따로 표시하며, 가이드는 해당 계좌의 평단가·수량 기준으로
  생성한다.
- 미국 주식의 소수점 수량(예: 0.35주)과 소수점 둘째 자리 달러 평단가를 입력할 수 있어야 한다.
- 한국 주식 평단가는 원 단위 정수, 미국 주식은 소수점 넷째 자리까지 허용한다.
- 자정(KST) 직전에 시작한 가이드 요청이 자정 이후 완료되면 요청을 시작한 날짜의 횟수로 계산한다.
- 두 개의 브라우저 탭에서 동시에 가이드를 눌러도 하루 한도를 넘지 않는다.
- AI 응답에 수치 오류나 판단 불가 응답이 나오더라도 그대로 기록하되, 모든 가이드에 "투자 판단의
  책임은 사용자에게 있다"는 면책 문구를 표시한다.
- 미국 장 시간은 한국 시간 기준 밤이므로, 장 상태(개장 전/장중/마감)를 시장별로 따로 판단한다.

## Requirements *(mandatory)*

### Functional Requirements

**계정 및 접근**

- **FR-001**: 시스템은 소유자 1인이 사용하는 개인 도구이며, 회원가입 기능은 없다. 최초 실행 시
  소유자가 비밀번호를 설정하고, 이후 모든 화면과 데이터 접근에는 비밀번호 로그인이 필요해야 한다.
- **FR-001a**: 로그인은 비밀번호 연속 5회 실패 시 일정 시간(15분) 잠겨야 하며, 로그인 세션은
  비활성 상태로 일정 시간(7일)이 지나면 만료되어야 한다.

**계좌 및 보유 종목**

- **FR-002**: 사용자는 계좌를 생성·이름 변경·삭제할 수 있어야 한다. 계좌명은 1~30자이며 소유자의
  계좌끼리 중복될 수 없다.
- **FR-003**: 사용자는 계좌에 보유 종목을 등록·수정·삭제할 수 있어야 한다. 필수 항목은 종목, 평단가,
  보유 수량이다.
- **FR-003a**: 소유자 전체 보유 종목은 최대 500개까지 등록할 수 있다. 초과 등록 시 저장하지 않고 상한을
  안내해야 한다.
- **FR-004**: 종목은 한국(KOSPI·KOSDAQ)과 미국(NYSE·NASDAQ·AMEX) 상장 종목 중에서 종목명 또는
  종목코드/티커로 검색해 선택해야 한다. 자유 입력 종목명은 허용하지 않는다.
- **FR-005**: 평단가는 종목 시장의 통화(한국 KRW, 미국 USD)로 입력·표시해야 한다.
- **FR-006**: 시스템은 한 계좌 안에서 같은 종목의 중복 등록을 막아야 한다.
- **FR-007**: 평단가와 수량은 0보다 커야 하며, 위반 시 저장하지 않고 입력란별 오류를 표시해야 한다.
- **FR-008**: 계좌나 보유 종목 삭제 전에는 확인 단계를 거쳐야 한다.

**현재가 표시**

- **FR-009**: 시스템은 보유 종목명 옆에 현재가, 전일 종가 대비 등락 금액, 등락률을 표시해야 한다.
- **FR-010**: 전일 종가 대비 상승은 빨간색, 하락은 파란색, 보합은 중립 색으로 표시해야 한다. 색상
  외에 ▲/▼ 기호나 +/− 부호를 함께 표시해 색만으로 정보를 전달하지 않아야 한다.
- **FR-011**: 시스템은 평단가 대비 평가손익(금액)과 수익률을 FR-010과 같은 색 규칙으로 표시해야 한다.
- **FR-012**: 장중에는 현재가를 최대 1분 간격으로 갱신하고, 마지막 갱신 시각을 표시해야 한다.
- **FR-013**: 시세 조회에 실패한 종목은 마지막으로 받은 값과 시각을 "지연/시세 없음" 상태로 표시하고,
  다른 종목 표시에 영향을 주지 않아야 한다.
- **FR-014**: 시장별 장 상태(개장 전, 장중, 마감, 휴장)를 표시해야 한다.

**AI 가이드**

- **FR-015**: 각 보유 종목에는 가이드 버튼이 있어야 한다.
- **FR-016**: 가이드 요청 시 시스템은 해당 종목의 최근 주가 흐름, 수급(거래량, 국내 종목은 투자자별 순매수·외국인
  보유 비율·공매도 비중), 사용자의 평단가·수량·평가손익·수익률을 AI에 제공해 분석을 요청해야 한다. AI 공급자가 웹
  검색을 지원하면 관련 국내외 이슈(정치·지정학·정책·산업·기업)를 검색하게 한다. (2026-11-05 확장)
- **FR-017**: 가이드 결과는 최소한 (1) 주가 흐름 분석 요약, (2) 사용자 보유 상황 진단, (3) 수급 분석,
  (4) 국내외 이슈(출처 링크 포함, 웹 검색 미지원 공급자는 미지원 안내), (5) 기술·수급·이슈·보유 상황을 묶은
  종합 판단, (6) 행동 가이드와 근거, (7) 주요 위험 요인, (8) 면책 문구를 포함해야 한다. 이슈는 실제 검색 결과에
  있는 출처만 보여 준다. (2026-11-05 확장)
- **FR-018**: 가이드는 **종목별로** 하루 최대 2회까지 요청할 수 있어야 한다. 같은 종목을 여러 계좌에
  보유한 경우 계좌와 관계없이 그 종목의 합산 횟수로 계산한다. 하루의 기준은 한국 시간(KST)
  00:00~23:59이며, 요청을 시작한 시각의 날짜로 계산한다.
- **FR-019**: 시스템은 종목별 남은 가이드 사용 횟수를 버튼 근처에 표시하고, 한도 도달 시 버튼을 비활성화하며
  초기화 시각을 안내해야 한다.
- **FR-020**: AI 응답 실패·시간 초과 등으로 가이드를 받지 못한 경우 사용 횟수를 차감하지 않아야 한다.
- **FR-021**: 동시 요청(여러 탭, 연속 클릭)이 있어도 하루 한도를 초과해 가이드가 생성되지 않아야 한다.
- **FR-022**: 가이드 결과에는 생성한 AI 공급자와 모델 이름을 표시해야 한다.

**AI 공급자 키 등록과 선택**

- **FR-023**: 사용자는 지원되는 AI 공급자(최소 Claude, OpenAI)별로 자신의 API 키를 등록·교체·삭제할 수
  있어야 한다. AI 호출 비용은 사용자 본인의 키로 청구되며, 서비스는 공용 키를 제공하지 않는다.
- **FR-023a**: 시스템은 키 저장 전에 해당 공급자에 유효한 키인지 확인하고, 유효하지 않으면 저장하지
  않아야 한다.
- **FR-023b**: 저장된 키는 암호화해 보관하고, 화면·로그·오류 메시지·가이드 기록 어디에도 원문을
  노출하지 않아야 한다. 화면에는 끝 4자리만 표시한다.
- **FR-023c**: 사용자는 키가 등록된 공급자 중 하나를 가이드용으로 선택해 저장할 수 있어야 한다. 키가
  하나만 등록되면 그 공급자가 자동 선택되며, 키가 없는 공급자는 선택할 수 없다.
- **FR-023d**: 등록된 키가 없으면 가이드 버튼을 눌렀을 때 요청하지 않고 키 등록 화면으로 안내해야 한다.
- **FR-023e**: 공급자 오류는 "키 확인 필요(인증 실패·잔액 부족)"와 "일시 장애(시간 초과·서버 오류)"를
  구분해 안내해야 한다.
- **FR-024**: 공급자 목록은 서비스 변경 없이 새 공급자를 추가할 수 있는 구조여야 한다.

**가이드 기록**

- **FR-025**: 성공한 모든 가이드는 요청 시각, 계좌, 종목, AI 공급자·모델, 요청 당시 현재가·평단가·
  수량·수익률 스냅샷, 가이드 본문과 함께 기록되어야 한다.
- **FR-026**: 사용자는 종목별 가이드 기록을 최신순으로 조회할 수 있어야 한다.
- **FR-027**: 보유 종목을 삭제해도 그 종목의 가이드 기록은 유지되어야 한다. 계좌 삭제 시에도 기록은
  유지되며 "삭제된 계좌"로 표시된다.
- **FR-028**: 가이드 기록은 사용자가 수정할 수 없다.

### Key Entities

- **소유자(Owner)**: 플랫폼을 사용하는 유일한 사람. 로그인 비밀번호와 선택한 AI 공급자를 가진다.
- **계좌(Account)**: 사용자가 이름 붙인 증권 계좌. 사용자에 속하며 여러 보유 종목을 가진다.
- **종목(Security)**: 시장(한국/미국), 거래소, 종목코드/티커, 종목명, 거래 통화로 식별되는 상장 주식.
- **보유 종목(Holding)**: 특정 계좌에 있는 특정 종목과 평단가·보유 수량. 계좌 안에서 종목당 하나.
- **시세(Quote)**: 종목의 현재가, 전일 종가, 등락, 기준 시각, 장 상태.
- **AI 공급자 키(AI Provider Credential)**: 공급자별로 소유자가 등록한 API 키(암호화 보관), 등록일,
  마지막 확인 결과. 공급자당 하나.
- **가이드 기록(Guide Record)**: 한 번의 성공한 가이드 결과. 요청 시각, 공급자·모델, 요청 당시 보유·
  시세 스냅샷, 가이드 본문을 가지며 수정할 수 없다.
- **가이드 사용량(Guide Usage)**: 날짜(KST)와 종목별 가이드 사용 횟수. 하루 한도 판단의 근거.

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 처음 쓰는 사용자가 계좌 1개를 만들고 종목 1개를 등록하는 데 2분 이내가 걸린다.
- **SC-002**: 보유 종목 50개인 사용자가 목록을 열었을 때 2초 안에 모든 종목의 현재가가 보인다.
- **SC-003**: 장중 표시되는 현재가는 실제 시세 대비 최대 1분 이내로 최신이다.
- **SC-004**: 등락 색상 표시는 상승·하락·보합 테스트 사례 100%에서 규칙과 일치한다.
- **SC-005**: 가이드 요청의 95%가 30초 이내에 결과를 보여준다. 웹 검색으로 이슈를 분석하는 공급자(Claude)는
  60초 이내다. (2026-11-05 확장: 웹 검색 시간 반영, 생성 타임아웃 120초)
- **SC-006**: 동시 요청 시나리오를 포함한 모든 테스트에서 종목별 하루 가이드 한도(2회)를 초과한 생성이
  0건이다.
- **SC-009**: 등록된 API 키 원문이 화면·로그·저장된 기록에서 발견되는 경우가 0건이다.
- **SC-007**: 성공한 가이드의 100%가 기록에 남고, 기록에서 요청 당시 스냅샷 값을 확인할 수 있다.
- **SC-008**: 사용자 테스트에서 참가자의 90% 이상이 안내 없이 가이드 버튼을 찾아 결과를 확인한다.

## Assumptions

- 사용자 입력 항목(계좌명·종목명·평단가)에 **보유 수량**을 추가했다. 평가손익과 "나의 상황에 맞는
  가이드"를 계산하려면 수량이 필요하기 때문이다.
- 현재가의 상승/하락 색상은 한국 증권 관례대로 **전일 종가 대비**로 판단한다.
- 시세는 실시간이 아니라 최대 1분 지연을 허용한다. 미국 주식은 정규장 시세 기준이며 프리·애프터마켓은
  v1 범위에서 제외한다.
- 미국 주식은 달러 그대로 표시하며, 원화 환산과 계좌·전체 합산 평가액은 v1 범위에서 제외한다.
- 매수·매도 거래 내역 입력과 평단가 자동 계산은 v1 범위에서 제외한다. 사용자가 평단가를 직접 입력한다.
- 증권사 계좌 연동(자동 동기화)은 v1 범위에서 제외한다.
- 가이드는 투자 참고 정보이며 투자 자문이 아니다. 모든 가이드에 면책 문구를 표시한다.
- 소유자 1인용이므로 회원가입·비밀번호 찾기(이메일)·다중 사용자 권한은 범위에서 제외한다. 비밀번호를
  잊으면 운영 환경에서 직접 재설정한다.
- 가이드 기록은 소유자가 직접 삭제하지 않는 한 계속 보관한다.
- 시세 정보와 종목 목록은 외부 시세 제공 서비스에서 받아오며, 한국·미국 시장을 모두 지원하는 제공자가
  필요하다(구체 선정은 계획 단계에서 결정).
- 공급자별 사용 모델은 공급자마다 기본 모델 하나로 고정하며, 모델 선택 기능은 v1 범위에서 제외한다.
- 하루 2회 한도는 AI 비용 통제보다 과도한 반복 조회를 막기 위한 사용 규칙이다(비용은 사용자 키로
  청구).
- 웹 브라우저(데스크톱 우선, 모바일 화면 대응)로 사용한다.
